# Changelog

## 1.1.1

## 1.1.0

- Expanded from 60 to 500 vocabulary entries: 100 each for software engineering, welding, electrical engineering, cooking and ordering.
- Added 440 icons, German/Hungarian meanings and bilingual example sentences.
- Preserved the original 60 word IDs for compatible saved learning progress.
- Added a word picker for direct navigation through each category.
- Practice now covers the full category in five-pair rounds without repeating completed words within a cycle.
- Saved category practice coverage and added cycle-completion feedback.
- Replaced the fixed home-screen word total with a calculated total.
- Added regression tests for 100-word exercise coverage, saved coverage, new cycles, partial remainders and legacy IDs.
- Refreshed documentation and Android emulator screenshots.

## 1.0

- Initial five-category Android app with 60 vocabulary entries.
- Matching exercises, text-to-speech and locally saved learning progress.
- GitHub Actions checks and automatic APK prereleases.
